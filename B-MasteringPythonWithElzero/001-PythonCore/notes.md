

# دليل أنواع البيانات في بايثون (Python Data Types Guide)

تُعد بايثون لغة برمجة كائنية التوجه (OOP)، حيث تُعتبر كافة أنواع البيانات فيها فئات (Classes)، والقيم التي ننشئها هي كائنات (Objects) من هذه الفئات.

## 1. الأنواع العددية (Numeric Types)

### أ- الأعداد الصحيحة (`int`)
تمثل الأعداد الصحيحة بدون كسور عشرية، ويمكن أن تكون موجبة أو سالبة.
*   **مثال:** `x = 50`
*   **أهم العمليات:** الجمع `+` | الطرح `-` | الضرب `*` | القسمة `/` | باقي القسمة `%` | الأس `**`.

### ب- الأعداد العشرية (`float`)
تمثل الأعداد التي تحتوي على نقطة عشرية (Floating-point values).
*   **مثال:** `y = 4.6`
*   **دالة التقريب:** `round(number, ndigits)` تستخدم لتقريب الرقم العشري.

---

## 2. النصوص أو السلاسل النصية (`str`)

تُعتبر السلاسل النصية من أكثر أنواع البيانات شعبية وهي غير قابلة للتعديل (Immutable). يتم إنشاؤها باستخدام علامات تنصيص مفردة `' '` أو مزدوجة `"` أو ثلاثية `''' '''` للنصوص المتعددة الأسطر.

*   **مثال:** `name = "Harvard CS50"`

### أهم ميثودز (Methods) السلاسل النصية:

| الميثود | الوصف | مثال |
| :--- | :--- | :--- |
| `strip()` | إزالة المسافات من البداية والنهاية. | `" hello ".strip()` -> `"hello"` |
| `upper()` | تحويل كافة الحروف إلى حروف كبيرة. | `"hi".upper()` -> `"HI"` |
| `lower()` | تحويل كافة الحروف إلى حروف صغيرة. | `"HI".lower()` -> `"hi"` |
| `title()` | تحويل الحرف الأول من كل كلمة إلى حرف كبير. | `"hello world".title()` -> `"Hello World"` |
| `capitalize()` | تحويل الحرف الأول فقط من السلسلة إلى حرف كبير. | `"hi".capitalize()` -> `"Hi"` |
| `split(sep)` | تقسيم النص إلى قائمة (List) بناءً على فاصل معين. | `"a,b".split(",")` -> `['a', 'b']` |
| `join(seq)` | تجميع عناصر قائمة في نص واحد باستخدام فاصل. | `"-".join(['a','b'])` -> `"a-b"` |
| `replace(old, new)` | استبدال نص قديم بنص جديد. | `"cat".replace("c", "h")` -> `"hat"` |
| `startswith(prefix)` | التحقق مما إذا كان النص يبدأ بقيمة معينة (True/False). | `"hi".startswith("h")` |
| `endswith(suffix)` | التحقق مما إذا كان النص ينتهي بقيمة معينة. | `"file.py".endswith(".py")` |
| `find(sub)` | إرجاع أول فهرس (Index) يظهر فيه النص الفرعي. | `"hello".find("o")` -> `4` |
| `isalpha()` | التحقق مما إذا كان النص يتكون من حروف فقط. | `"abc".isalpha()` |
| `isdigit()` | التحقق مما إذا كان النص يتكون من أرقام فقط. | `"123".isdigit()` |

## 3. القوائم (`list`)

هي مجموعة مرتبة من العناصر القابلة للتعديل (Mutable) ويمكن أن تحتوي على أنواع بيانات مختلطة. يتم تعريفها باستخدام الأقواس المربعة `[ ]`.

*   **مثال:** `students = ["Harry", "Ron", "Hermione"]`

### أهم ميثودز القوائم:

| الميثود | الوصف | مثال |
| :--- | :--- | :--- |
| `append(x)` | إضافة عنصر جديد إلى نهاية القائمة. | `mylist.append("new")` |
| `remove(x)` | حذف أول عنصر يحمل القيمة المحددة. | `mylist.remove("item")` |
| `pop(i)` | حذف وإرجاع العنصر الموجود في الفهرس المحدد. | `mylist.pop(0)` |
| `clear()` | حذف كافة العناصر من القائمة. | `mylist.clear()` |
| `sort()` | ترتيب القائمة (تصاعدياً بشكل افتراضي). | `mylist.sort()` |
| `reverse()` | عكس ترتيب العناصر في القائمة. | `mylist.reverse()` |
| `index(x)` | البحث عن قيمة معينة وإرجاع مكانها (الفهرس). | `mylist.index("item")` |

---

## 4. التابل (الصفّية) (`tuple`)

تشبه القوائم ولكنها **غير قابلة للتعديل** (Immutable). تُستخدم لحماية البيانات من التغيير العرضي. تُعرف بالأقواس الدائرية `( )` أو حتى بالفواصل فقط.

*   **مثال:** `dimensions = (1920, 1080)`
*   **الميثودز:** تدعم عمليات محدودة مثل `index()` و `count()` لأنها غير قابلة للتعديل.

---

## 5. القواميس (`dict`)

مجموعة غير مرتبة من أزواج "المفتاح والقيمة" (Key-Value pairs). المفاتيح يجب أن تكون فريدة. تُعرف باستخدام الأقواس المتعرجة `{ }`.

*   **مثال:** `student = {"name": "Harry", "house": "Gryffindor"}`

### أهم ميثودز القواميس:

| الميثود | الوصف |
| :--- | :--- |
| `get(key)` | إرجاع قيمة المفتاح المحدد. |
| `keys()` | إرجاع قائمة بكافة المفاتيح الموجودة في القاموس. |
| `values()` | إرجاع قائمة بكافة القيم الموجودة في القاموس. |
| `items()` | إرجاع قائمة من التابلز (كل تابل يحتوي على مفتاح وقيمة). |
| `update(dict2)` | تحديث القاموس بإضافة عناصر قاموس آخر. |
| `clear()` | حذف كافة العناصر من القاموس. |
| `pop(key)` | حذف المفتاح المحدد وإرجاع قيمته. |

---

## 6. المجموعات (`set`)

مجموعة غير مرتبة من العناصر الفريدة (لا تقبل التكرار). تستخدم لإزالة التكرارات وإجراء العمليات الرياضية مثل الاتحاد والتقاطع.

*   **مثال:** `unique_houses = {"Gryffindor", "Slytherin", "Ravenclaw"}`

### أهم ميثودز المجموعات:

| الميثود | الوصف |
| :--- | :--- |
| `add(x)` | إضافة عنصر جديد للمجموعة. |
| `remove(x)` | حذف عنصر محدد (يسبب خطأ إذا لم يوجد). |
| `discard(x)` | حذف عنصر محدد (لا يسبب خطأ إذا لم يوجد). |
| `union(s)` | إرجاع مجموعة جديدة تحتوي على اتحاد مجموعتين. |
| `intersection(s)` | إرجاع التقاطع بين مجموعتين. |
| `difference(s)` | إرجاع الفرق بين مجموعتين. |
| `clear()` | تفريغ المجموعة تماماً. |

---

## 7. الأنواع الأخرى

*   **النوع المنطقي (`bool`):** يحمل إحدى قيمتين فقط: `True` (صح) أو `False` (خطأ).
*   **النوع الخالي (`NoneType`):** يمثله الكلمة المحجوزة `None` للتعبير عن غياب القيمة.
